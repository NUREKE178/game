## 🎮 Ойын туралы

Сен — **Дала рухы**, кішкентай әрі қайсар тіршілік иесі. Үш деңгей арқылы Сарыарқа даласын кесіп өт:

| Деңгей | Аты | Ерекшелігі |
|---|---|---|
| 1 | **Дала Таңы** — Steppe Dawn | Оқу деңгейі, шұңқырлар, батут |
| 2 | **Сарыарқа Желі** — Wind of Saryarka | Тікенектер, жүректер, чекпоинт |
| 3 | **Аврора Түні** — Night of the Aurora | Қиын, 2 чекпоинт, көп тікенек |

Әр деңгейде:
- 🪙 тиындар — 31/48/46 дана
- 👾 слаймдар — таптасаң жарылады
- ❤️ жүректер — бір жүрек толтырады (барлығы 3)
- 🟩 батут — жоғары ату
- 🚩 чекпоинт туы — өлу/құлаудан кейін сонда ораласың
- 🚩 қызыл ту — деңгейдің соңы, жеңіс!

**Жұлдыздар:** 1 — деңгейді бітірсең, 2 — тиынның жартысын жинасаң, 3 — барлығын жинасаң.

### Басқару

| Перне | Әрекет |
|---|---|
| `A` / `←` , `D` / `→` | жүру |
| `Space` / `W` / `↑` | секіру (басып тұрсаң — жоғары) |
| екінші рет `Space` | қос секіру |
| `X` / `Shift` / `J` | зымырау (dash) — ауада да болады, 0.85с салқындау |
| `Esc` / `P` | тоқтату (пауза) |
| `Enter` / `Space` | мәзірде растау |

Койот-тайм (0.12с) және jump-buffer (0.14с) бар — секіру кешірімді, Celeste сияқты.

## 🚀 Қалай қосу керек

1. **Godot 4.7.2-stable** (немесе 4.3+) қондыр: https://godotengine.org/download
2. Осы репозиторийді клонда:
   ```bash
   git clone https://github.com/NUREKE178/game.git
   cd game
   ```
   Немесе Arena-дағы осы бранчты: `arena/03573910-game`
3. Godot-ты аш → **Import** → `project.godot` файлын таңда.
4. **▶ Play** бас (немесе `F5`). Басты мәзірден деңгей таңда.

> Сыртқы ассет жоқ — барлық графика мен дыбыс кодпен салынған. Интернетсіз де жұмыс істейді.

### Экспорт

`Project → Export` → Windows / macOS / Linux / Web (HTML5). Бір түйме.

## 🏗️ Құрылым

```
project.godot               # 1280×720, canvas_items, autoload SFX+Game
scenes/
  main_menu.tscn            # Басты мәзір (кодпен UI)
  game.tscn                 # Ойын сахнасы (деңгейді код салатын)
scripts/
  game_state.gd             # Autoload Game — сақтау, деңгей ауысу
  sfx.gd                    # Autoload SFX — толқын синтез (22050 Гц)
  levels.gd                 # 3 деңгейдің ASCII картасы (148×17, TILE=64)
  player.gd                 # Рух — қозғалыс, squash&stretch, i-frames
  slime.gd                  # Жау
  coin.gd / heart_pickup.gd / spring_pad.gd
  checkpoint.gd / goal_flag.gd / spike.gd
  parallax_bg.gd            # Град. аспан, күн/ай, бұлт, төбе параллакс
  hud_view.gd               # HUD — жүрек, тиын, уақыт, зымырау шкаласы
  game.gd                   # Деңгейді құру, камера, juice, жеңіс/жеңіліс
  main_menu.gd              # Мәзір — карточкалар, дыбыс, басқару нұсқау
```

### Дизайн шешімдері (juice!)

- **Squash & stretch** — секіру/қону/зымырауда масштаб серіппемен
- **Coyote time + jump buffer** — кешірімді платформер
- **Screen shake + afterimage** — зымырау мен зақымда
- **Confetti / dust / floating text** — тиын, таптау, чекпоинт
- **Параллакс** — 2 төбе қабаты + бұлт + күн пульсі + түнгі жұлдыздар
- **Процедуралдық дыбыс** — 13 эффект, AudioStreamWAV синтез, нөл файл

Карта легендасы: `#` блок, `P` старт, `G` ту, `S` слайм, `C` чекпоинт, `^` тікен, `o` тиын, `h` жүрек, `b` батут, `T/Y/R` ағаш/киіз үй/тас (декор).

### Pixel-art assets

`assets/bg/menu_bg.png` — AI-generated original background for this project. The
sprite sheet and nine-slice UI textures in `assets/sprites/` and `assets/ui/`
are project-original pixel art, generated by `tools/make_pixel_assets.py`
(Python and Pillow are only needed to regenerate the PNGs). The spirit sheet
has four rows: idle, run, jump and dash. The UI and pickups share the same
palette and use nearest-neighbour texture filtering.

**Тексеру:** Godot 4-те жобаны импорттап, әр деңгейде Ойнау → Esc →
Жалғастыру, Қайта ойнау және Мәзір батырмаларын тексеріңіз; туды ұстап,
жеңіс экраны мен келесі деңгейді де байқап көріңіз.

Интерфейсте Nunito қарпі қолданылады: Medium — мәтінге, ExtraBold —
тақырыптар мен батырмаларға. Қазақ әріптері бар. Лицензиясы мен дереккөзі:
`assets/fonts/OFL-Nunito.txt` және `assets/fonts/README.md`.
